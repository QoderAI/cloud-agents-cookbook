# Support

- Use an Issue to report a problem with published Cookbook content, templates, schemas, or repository tooling.
- Use a Discussion to ask which content type, category, or template fits a proposed contribution.
- Use the repository Security tab to report vulnerabilities or sensitive disclosure.
- Use the Qoder product support channel for account, billing, availability, or production service incidents.

Do not post credentials, customer data, private logs, internal URLs, or personal information in public Issues or Discussions.
