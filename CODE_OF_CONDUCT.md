# Code of Conduct

## Our commitment

We are committed to a welcoming, safe, and constructive community for everyone, regardless of background, identity, experience, or level of expertise.

## Expected behavior

- Be respectful, specific, and patient.
- Discuss the work rather than attacking the person.
- Accept factual correction and explain disagreements with evidence.
- Respect privacy, copyright, customer confidentiality, and security boundaries.
- Help contributors understand how to improve a submission.

## Unacceptable behavior

Harassment, threats, discriminatory language, doxxing, sexualized attention, deliberate disclosure of private information, spam, and sustained disruption are not acceptable.

## Enforcement

Report conduct concerns privately through the repository's security reporting channel when disclosure in an Issue would expose personal or sensitive information. Maintainers may edit or remove comments, close contributions, temporarily restrict participation, or permanently ban participation when necessary. Enforcement decisions should be proportionate, documented privately, and avoid exposing reporters.

This code applies in repository Issues, Discussions, pull requests, review comments, and other official project spaces.
